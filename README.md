# 订阅账本

<img src="logo.png" alt="订阅账本 Logo" width="120" height="120">

一个 AstrBot 插件，用来记录订阅服务、查看预计支出，并在续费或试用结束前发送私聊提醒。你可以在插件页面管理记录，也可以让支持工具调用的 Agent 增删改查。

## 能做什么

- 记录服务名称、金额、币种、周期、付款方式、续费方式、标签、试用期和备注。
- 在 AstrBot 插件页面新增、编辑、暂停、删除、搜索和导出订阅；支持深色与浅色主题。
- 以原币种分别显示月均、年均预计支出，也可用参考汇率换算为指定币种。
- 选择提前提醒、到期当天提醒或两次都提醒；时区可跟随服务器或手动指定。
- 服务图标可根据官网域名获取，也可填写自定义图片链接；获取失败时显示文字标识。

## 安装与开始使用

在 AstrBot 插件市场搜索「订阅账本」并安装；也可以在管理面板的「插件」页面通过 URL 安装本仓库：

`https://github.com/echo-zzxi/astrbot_plugin_subscription_ledger`

安装后：

1. 私聊 Bot 发送 `/订阅`，登记当前私聊身份和提醒会话。
2. 打开插件详情里的「订阅账本」页面，添加第一项订阅。也可以让 Agent 添加，例如：“记录我的云盘会员，每月 25 元，11 月 10 日续费，提前 3 天提醒。”
3. 在插件设置或账本页面调整保存方式、提醒时区和币种换算。要用自然语言管理，需在 AstrBot 中启用本插件的 Agent 工具，并使用支持工具调用的模型。

插件提供 `subscription_list`、`subscription_summary`、`subscription_add`、`subscription_update`、`subscription_delete` 五个 Agent 工具。群聊中不提供订阅读写。

从 0.4.4 起，Agent 工具会把 JSON 结果返回给模型。列出、新增和修改会返回完整订阅字段及 ID，删除会返回已删记录的 ID 和名称；普通 `/订阅` 命令仍直接回复私聊。更新已安装的市场插件时，请在 AstrBot 插件管理页执行更新，然后让 Agent 试一次「列出订阅 → 修改一条 → 再列出」。

## 账户与隐私

**新安装默认分账户保存**：不同私聊身份的订阅分别保存。你也可以切换到统一账本；此时**所有能私聊这个 Bot 的人都能读取、修改和删除整份账本**。统一账本只适合受信任用户使用的私人 Bot，提醒会发送到设置中指定的一个私聊。

订阅数据保存在 AstrBot 的插件数据目录中，不写入插件代码目录。导出的 JSON 包含订阅内容，请自行妥善保管。管理页面仅供 AstrBot 管理员使用。

使用自动换算时，插件会向 [Frankfurter](https://frankfurter.dev/) 请求所选币种的参考汇率；使用自动图标时，会向 `logo.debounce.com` 请求公开服务域名的图标。自定义图标由浏览器向你填写的地址加载。让 Agent 处理订阅时，数据也会按照你配置的模型服务规则处理。

## 当前边界

- 金额和下次日期是预计值；插件不会付款，也不会核对实际扣款。
- 汇率只供参考；获取失败时改为按币种分别展示。
- 提醒每 5 分钟检查一次。停机跨过到期日不会补发过去的提醒；极端情况下，发送成功但记录状态前进程中断，重启后可能重复提醒。

此前在 AstrBot 4.28.1 上确认了插件加载、管理页基础访问和数据库保留。0.4.4 的 Agent 结果回传修复依据该版本执行器源码完成，真实私聊链式操作及提醒投递尚待更新后验证，欢迎反馈。
